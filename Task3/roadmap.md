# Роадмап

## Q1: Анализ исходного состояния
Проведение комплексного аудита существующей ИТ-инфраструктуры с фиксацией всех источников данных, бизнес-процессов и системных зависимостей.

**Ответственные**: Архитектурная группа

**Обоснование**: Результаты анализа позволят провести последующую миграцию данных без потерь критической информации и обеспечат снижение затрат на хранение и поддержку за счет устранения дублирования.

## Q1-Q2: Пилотная реализация Data Lake
Создание первого рабочего контура Data Lake с интеграцией ключевых источников (клиентские и финансовые данные).

**Ответственные**: Data Engineering

**Обоснование**: Значительное ускорение доступа к новым источникам данных для аналитики и снижение операционной нагрузки на существующие системы хранения.

## Q2: Модернизация интеграционного уровня
Рефакторинг шины данных с заменой Apache Camel на современный стек Kafka + KSQL для обработки потоковых данных.

**Ответственные**: Интеграционная команда

**Обоснование**: Новые сервисы подключаются быстрее, а общая стабильность платформы повышается.

## Q2-Q3: Внедрение каталога данных
Развертывание системы управления метаданными (Apache Atlas или аналог) для создания единого каталога данных организации.

**Ответственные**: Data Governance

**Обоснование**: Сокращение временных затрат на поиск и верификацию информации, а также повышение надежности принимаемых бизнес-решений за счет использования проверенных данных.

## Q3: Запуск Портала самообслуживания
Разработка портала самообслуживания для предоставления данных бизнес-пользователям.

**Ответственные**: BI / Frontend / Backend

**Обоснование**: Повышение скорости принятия решений за счет оперативного доступа к аналитике и оптимизация ресурсов IT-департамента за счет сокращения рутинных запросов.

## Q3-Q4: Миграция с устаревшего DWH
Поэтапный перенос данных из SQL Server на современную платформу (Databricks/Snowflake).

**Ответственные**: Data Engineering

## Q4: Внедрение системы контроля доступа
Настройка централизованного управления доступом на основе Keycloak с поддержкой RBAC/ABAC политик.

**Ответственные**: Безопасность + DevOps

**Обоснование**: Снижение потенциальных юридических и финансовых рисков, связанных с нарушениями требований регуляторов, и укрепление деловой репутации компании как надежного хранителя данных.
